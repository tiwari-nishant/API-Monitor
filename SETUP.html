🚀 OpenBMC GUI Monitor

Complete Setup Guide - From Zero to Hero

Welcome! This guide will walk you through setting up the OpenBMC GUI Monitor extension from scratch. Follow each step carefully for a smooth installation.
1

Prerequisites Check

Before you begin, ensure you have the following:

  • Firefox Browser (version 78 or higher)
  • Basic understanding of browser extensions
  • Text editor (VS Code, Sublime, or any editor)
  • Terminal/Command Prompt access
Note: This extension is specifically designed for Firefox. Chrome/Edge support is planned for future releases.
2

Get the Extension Files

Clone the repository to get the extension files:

Clone from Git Repository

git clone https://github.com/tiwari-nishant/API-Monitor.git
cd API-Monitor
Tip: Choose a permanent location for the extension files. Don't place them in temporary folders like Downloads or Desktop.
3

Verify File Structure

Ensure your directory contains all required files:

API-Monitor/
├── manifest.json          # Extension configuration
├── background/
│   ├── background.js      # Main coordinator
│   ├── request-interceptor.js  # Network capture
│   └── storage-manager.js      # Data management
├── sidebar/
│   ├── sidebar.html       # UI structure
│   ├── sidebar.js         # UI logic
│   └── sidebar.css        # Styling
├── utils/
│   └── request-parser.js  # Request parsing
├── icons/
│   ├── icon-16.png
│   ├── icon-48.png
│   └── icon-96.png
└── README.md              # Documentation
Important: If any files are missing, the extension will not work properly. Re-download or check your extraction.
4

Generate Icons (Optional)

If PNG icons are missing, you can generate them:

  1. Open icons/create-icons.html in your browser
  2. Click the download buttons for each icon size
  3. Save the icons in the icons/ folder
Note: The extension can work with SVG icons if PNG files are not available. This step is optional.
5

Load Extension in Firefox

Follow these steps to install the extension:

  1. Open Firefox
  2. Navigate to: about:debugging in the address bar
  3. Click: "This Firefox" in the left sidebar
  4. Click: "Load Temporary Add-on..." button
  5. Navigate to: Your extension folder
  6. Select: manifest.json file
  7. Click: "Open"
📸 Screenshot: Firefox about:debugging page
Success! You should see "OpenBMC GUI Monitor" appear in the list of temporary extensions.
6

Verify Installation

Check that the extension is working correctly:

  • Extension icon appears in Firefox toolbar
  • No error messages in about:debugging
  • Extension shows as "Running"
  • Version number matches (1.0.0)
Troubleshooting: If you see errors, check the Browser Console (Ctrl+Shift+J) for details.
7

Open the Sidebar

Access the extension's interface:

Method 1: Click Extension Icon

  1. Look for the extension icon in the Firefox toolbar
  2. Click the icon
  3. Sidebar opens on the right side

Method 2: Firefox Menu

  1. Go to: View → Sidebar
  2. Select: "OpenBMC GUI Monitor"
📸 Screenshot: Extension sidebar interface
8

Configure Settings (Optional)

Customize the extension for your needs:

Remove Redfish URL Filter

By default, only Redfish API calls are captured. To capture all requests:

  1. Open: background/request-interceptor.js
  2. Find the shouldCaptureUrl() method (around line 26)
  3. Comment out the Redfish filter section
  4. Return true to capture all requests
shouldCaptureUrl(url) {
  // Exclude node_modules and src/views
  if (url.includes('/node_modules/') || url.includes('/src/views/')) {
    return false;
  }
  
  // Capture all requests (Redfish filter removed)
  return true;
}

Remove Domain Filter (stglabs)

To capture requests from any domain:

  1. Open: background/request-interceptor.js
  2. Find handleBeforeRequest() method (around line 203)
  3. Comment out the stglabs check
// Comment out this section:
/*
if (!this.isStglabsTab()) {
  console.log('Ignoring request - active tab is not a stglabs domain');
  return;
}
*/
Important: After making changes, reload the extension in about:debugging.
9

Test the Extension

Verify everything works correctly:

  1. Open the sidebar (if not already open)
  2. Click "Start Recording" button
  3. Navigate to a website (e.g., OpenBMC interface)
  4. Perform some actions that trigger API calls
  5. Check the sidebar - requests should appear
  6. Click a request to view details
  7. Click "Stop Recording" when done
  8. Click "JSON" to export data
Success! If you see requests appearing and can export them, the extension is working perfectly!
10

Troubleshooting Common Issues

Extension Not Loading

  • Check that manifest.json is valid JSON
  • Verify all file paths in manifest.json are correct
  • Look for errors in Browser Console (Ctrl+Shift+J)

No Requests Captured

  • Ensure recording is started (button should show "Stop Recording")
  • Check URL filters in request-interceptor.js
  • Verify the website is making network requests
  • Check domain filter (stglabs) if applicable

Sidebar Not Opening

  • Try restarting Firefox
  • Reload the extension in about:debugging
  • Check if sidebar is enabled in Firefox settings

Export Not Working

  • Check Firefox download permissions
  • Verify storage permissions in manifest.json
  • Look for errors in Browser Console
Still Having Issues? Check the TROUBLESHOOTING.md file for more detailed solutions.
